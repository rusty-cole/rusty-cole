# Repository instructions

- Read `README.md` for the current repository scope before editing.
- Invoke `visual-development` before work that adds or materially changes a user journey, cross-module flow, workflow, integration, or architecture boundary; do not create a visual for routine work.
- For each material connection, make direction, mechanism, payload or purpose, owner, and `CURRENT`/`CANDIDATE`/`LATER`/`UNKNOWN` status explicit. The final receipt must state `Visual impact: Updated` or `Visual impact: None`.
- Do not add validators, hooks, or diagram systems merely to comply with this procedure.
